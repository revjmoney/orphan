Real NES pads

⚠ Disconnect every hashboard firstUnplug all hashboards from J1..J9 before you plug in a pad. Any header can be a pad port.

3.3 V only: the header pins are not 5 V tolerant. Power the pad from pin 16 (3.3 V), never from 5 V.

Not tested with a NES controller, yet.

  1. Build the adapter as drawn (an NES extension cable's socket end works well: find each wire with a continuity tester). Tie pin 5 (PLUG) to GND: that tells Orphan a pad is plugged in.
  2. Unplug every hashboard, then plug the adapter into a header on the S9 board (stock boards only have headers on J6, J7 and J8). Optional: ORPHAN_NES_PADS_NEVER=6,7 lists headers that are never driven or read.
  3. Pick the headers before starting the console: ORPHAN_NES_PADS=7,8 (or the line 7,8 in /etc/orphan/nespads). The default is J1 and J2; off turns real pads off.
  4. This panel shows "adapter found" and lights each button as you press it. Real pads and the browser pads work together.
